# 使用 Nickel

## 第一次启动

将 Nickel 放在可写文件夹中。首次运行会在程序旁建立 `.minecraft` 游戏目录和 `Nickel` 设置目录；macOS 放在完整 `.app` 的同级目录。

首页提供账号选择与启动卡片。点「选择版本」管理已有实例，在「资源 → 原版游戏」安装游戏与加载器。

## 账号与角色

- **微软正版**：选择「正版」，点击登录，在浏览器输入设备码并完成授权。
- **皮肤站**：选择「皮肤站」，填写 LittleSkin 或兼容 Yggdrasil 的站点地址，用站点账号登录；有多个角色时再选一个角色。
- **离线**：在「设置 → 账号与隐私」设置离线用户名。

皮肤站地址可以是站点根或完整 API 根；留空使用 LittleSkin。首页登录态的账号切换入口列出已保存账号；角色操作入口用于打开官方皮肤页或选择皮肤站角色。

微软登录需要配置公共客户端 ID，具体操作见 [开发文档](development.md#可选-api-配置)。

## 实例与游戏设置

「选择版本」管理多个游戏目录。点实例卡片即可选中并回到首页；卡片右下角提供收藏、删除与实例设置。

- 「设置 → 游戏」保存全局内存、Java、窗口和启动参数。
- 「实例设置」可逐项继承或覆盖全局值，并管理图标、名称、Mod 和导出。
- 修改展示名不会移动实例目录。
- 「移出列表」解除目录登记；「删除目录」删除磁盘内容，操作前会确认。

Java 自动选择依据真实游戏与加载器版本。手动选择时，请选择满足要求的 64 位 Java。自动内存分配参考可用内存和启用的 Mod 数量；也可手动指定。

## 下载游戏与资源

在「资源 → 原版游戏」选择游戏版本，按需附加 Forge、NeoForge、Fabric、OptiFine 或 LiteLoader。主加载器互斥；版本卡片中可安装的构建可以勾选，其余条目保留说明或安装器另存入口。

在「资源 → 社区资源」搜索 Modrinth / CurseForge，按类型、游戏版本和加载器筛选。普通资源选择版本后打开另存为，整合包先输入实例名称再安装。

右下角下载按钮进入下载中心。版本和整合包依次安装，普通资源可并行；在任务卡中取消，等待收尾后继续下一项。

「设置 → 下载」分别调整版本列表、文件和社区 API 来源，并设置线程数与限速。官方自动模式在缓慢时尝试镜像，也可选择官方优先或镜像优先。

## 外观

「设置 → 外观」分别选择明暗模式和颜色主题：

- 明暗模式：跟随系统、亮色、暗色。
- 颜色主题：黑与白、翡翠绿、海蓝色、魅紫色、琥珀色、玫瑰红、镍光、铜霞、深海、纸灯、四十二和自定义。切换主题时颜色与装饰淡入淡出。
- 自定义主题：选用后点击按钮进入独立的编辑页，调整色相、饱和度、亮度、顶栏色相偏移和顶部装饰，滑块改动即时生效。

可以选择本地图片或视频作为背景，调整模糊和遮罩。图片支持 PNG、JPEG、WebP、GIF、BMP、AVIF（不超过 32 MiB），视频支持 MP4、M4V、WebM、OGV（不超过 512 MiB，静音循环播放）。文件需要放在本地磁盘上；网络共享和映射网络盘上的文件请先复制到本地。设置背景后不显示主题自带的背景装饰，顶部装饰保留。

系统开启减少动态效果，或窗口被隐藏时，界面减少动画并暂停视频背景。

## Mod 与整合包

Mod 管理支持搜索、启用、禁用、删除、重复筛选与更新检查。更新后保留原有启用状态。

导出页提供两种格式：

| 格式 | 内容 |
| --- | --- |
| `.mrpack` | 标准 Modrinth 整合包 |
| 便携 ZIP | 标准包载荷，可附加 Nickel 发行程序、外观和可迁移的实例设置 |

标准导出支持原版、Forge、NeoForge、Fabric 与 Quilt。携带启动器或个性化时选择便携 ZIP；Windows 需要 WebView2，Linux 需执行权限，macOS 放置完整 `.app`。解压后首次运行会导入实例并补齐游戏文件。

## 数据与升级

配置选择优先级：显式便携包 → 已有 Nickel 系统配置 → 程序旁 `Nickel`。首次使用在程序旁创建 `Nickel`。

账号、密钥、实例和缓存从选定的完整目录读取。游戏优先使用已登记路径，不自动移动游戏目录。实例设置和档案分别保存为 `nickel.settings.json`、`nickel.profile.json`；便携标记为 `nickel.portable.json`。

| 文件 | 用途 |
| --- | --- |
| `settings.json` | 外观、下载与账号相关设置 |
| `accounts.json` / `active_account.json` | 账号与当前选择 |
| `credentials.key` | 已保存凭据的加密密钥 |
| `game.json` | 全局游戏设置 |
| `instances.json` | 游戏目录登记与标签 |

备份账号时一并保存整个配置目录，尤其是 `credentials.key`。

## 常见问题

| 现象 | 操作 |
| --- | --- |
| 启动按钮不可用 | 先选择实例，并确认账号或离线用户名 |
| 找不到 Java | 在游戏设置中重新扫描，或指定满足版本要求的 64 位 Java |
| 下载很慢 | 检查文件源、速度限制和线程数；列表慢时单独调整版本列表源 |
| 无法写入配置 | 把启动器移到可写文件夹，再重新打开 |
| 游戏退出 | 在错误弹窗打开日志目录，按提示检查 Java、内存和 Mod |
| 皮肤站角色不完整 | 在首页打开角色选择，使用已保存的登录信息重新取得角色列表 |

反馈故障时，请附 Nickel 版本、系统、游戏与加载器版本、复现步骤以及问题附近的日志，使用 [故障反馈模板](https://github.com/Nickel-Studio/Ni-Launcher/issues/new/choose)。
