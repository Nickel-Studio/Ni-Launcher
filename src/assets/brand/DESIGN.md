# Elemental Quiet

形体由清晰轮廓与克制的留白共同建立。N 与方点是固定识别，辅助图形以相同网格、边缘精度和空间节奏呈现。每一处比例经过细致推敲，小尺寸仍可辨认，完整组合保留呼吸空间。

黑、白与中性灰构成完整材料语言；少量颜色只承担类别与状态的信号。平面色块取代模拟金属和炫光，明暗关系服务于轮廓。精心校准的对比使图形在深浅界面中同样稳定。

方体用几何切面表示体积，而不借游戏纹理辨识对象。模块化切面将相同尺度转化为不同类别，圆角与内部间距保持一致。制作的精度来自反复调整，不来自堆叠细节。

文字稀少而必要。Ni 与 28 是元素符号和原子序数的隐约线索；类别字母是辅助信号，不与 Logo 争夺视线。排版与图形经过同样细致的对齐，边界与留白共同建立层级。

整套视觉在大横幅与小图标之间保持连续。以专业制作的严谨审视每一条边缘、每一处间距与每一种缩放，优先精修已有构成而非增加装饰；图形以安静、完整和可辨识为最终标准。
