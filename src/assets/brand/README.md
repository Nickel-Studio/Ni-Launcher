# Nickel 品牌资源

完整名称为 **Nickel**，简写为 **Ni**，中文为 **镍**。仓库名称为 **Ni-Launcher**。

本目录提供 N ＋方点简标、正反色应用图标、README 横幅和透明字标。横幅按原比例展示；浅底使用黑字版，深底使用白字版。图形保持中性黑白，不追加发光、金属渐变或拉伸。

品牌翻新只调整产品名称、Logo、应用图标和品牌展示。`src/assets/blocks/`、默认 Mod 图、游戏纹理与加载器图标属于功能资源，保留既有图片和分配映射。

`Ni` 是镍的元素符号，`28` 是原子序数。应用图标由 `Nickel.png` 生成：

```sh
pnpm tauri icon src/assets/brand/Nickel.png
```
